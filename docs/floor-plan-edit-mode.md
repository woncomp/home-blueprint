# 户型编辑模式：交互设计与实施计划

## 一、模式与操作习惯

### 1. 三个职责明确的模式

- **查看模式**：保持现有 3D 浏览、选中和墙面展开查看。
- **电路编辑**：保留现有强电箱拖动、墙面设备/端点、连线和删除电路实体功能；不再出现添加墙、删除墙等户型工具。
- **户型编辑**：切换到完全独立的 2D 顶视图，所有墙体新增、选择、删除、伸缩和平移只在这里进行。切换模式时退出未完成的画墙/拖动操作，并清理不兼容的选中状态。

### 2. 户型编辑工具栏

提供 `选择`、`正交画墙`、`任意画墙`、`删除墙`、`适应视图`，配合动态操作提示。

- **选择**：单击墙或控制点选中；单击空白清除选择。
- **正交画墙**：单击起点、再单击终点，墙自动锁定为水平或竖直方向。
- **任意画墙**：同样两次单击，但允许任意角度。两个画墙工具分开显示，不要求用户记忆隐藏快捷键。
- 画墙时实时显示预览、长度和角度；完成一堵后工具仍保持激活，可继续画下一堵，`Esc` 或切回“选择”退出。
- 默认吸附到 0.1m 网格、已有墙端点和墙面投影（便于建立转角/T 型连接）；按住 `Alt` 临时关闭吸附。短于 0.2m 的墙不创建。
- `Delete` 删除当前选中的墙，行为与现有删除墙一致；承载强电箱的墙仍禁止删除。

### 3. 顶视图导航

- 滚轮以鼠标位置为中心缩放。
- 在空白处按住左键拖动平移视图，不与“拖动墙体”混淆。
- “适应视图”将全部墙体重新缩放到画布中央；进入户型编辑和导入新数据时自动适应一次。
- 2D 坐标保持现有模型的俯视方向：X 向右、Z 向下，不使用 WASD 或 3D 旋转。

### 4. 墙长、方向与位置的编辑

- **拖动墙体**：在选择工具下拖动墙身，默认沿墙法线做“前后平移”，避免无意改变墙长和角度；显示实时位移量。
- **拖动独立端点**：自由调整该墙的端点，从而改变长度和方向；显示实时长度。
- **拖动转角/共端点交点**：重合的墙端只显示一个控制点，拖动时所有共用该点的墙端一起移动，各墙另一端保持不动，因此相关墙会自动伸缩或改变方向。
- **T 型交点**：识别“墙端落在另一堵墙内部”的连接。拖动该交点时沿宿主墙滑动，相连的墙端一起移动；户型编辑层不隐式拆墙（逻辑墙段的派生拆分只发生在电路编辑/预览层，见文末）。
- **精确长度**：选中墙后，右侧信息栏提供可编辑的长度字段；修改时保持墙的方向和起点不变，仅移动终点，并应用与拖动相同的连接联动和校验。
- 普通穿越且没有墙端参与的十字交叉不生成可拖控制点，避免为了移动交点而隐式拆分墙体或破坏电路归属。

### 5. 联动与数据安全规则

- 连接关系不写入 JSON，而是按端点重合、端点落在墙上的几何关系实时构建；只有吸附后真正重合/落在墙上的连接才联动。
- 平移墙时，共端点的相邻墙端随连接点移动；若被移动墙是 T 型连接的宿主墙，其上的相连墙端按相同的沿墙位置随动。被联动墙的另一端保持固定。
- 若某次拖动无法同时保持已有 T 型连接，则限制到可行方向或显示无效预览，不静默断开连接。
- 所有受影响墙统一检查最小长度及墙面元素边界。节点/设备/强电箱的 `pos` 为沿墙 0~1 归一化坐标，墙缩短时按相同比例随动、不会落出墙外；门仍是绝对米数，若缩短后会使门洞落在墙外，本次修改无效并给出提示。
- 墙的 `id`、墙高、厚度以及节点的 `wall/pos/face` 均保留，电路会随墙几何自动移动；每次修改后同步强电箱端子。删除墙的现有级联清理规则保持不变。
- 拖动过程中只重绘 2D SVG，松开鼠标且修改有效后再统一刷新 3D、房间和线路，避免每个鼠标事件都重建 3D 场景；`Esc` 可取消正在进行的拖动并恢复拖动前快照。

## 二、代码实施步骤

### 1. 页面结构与样式

- 修改 `index.html`：增加“户型编辑”模式按钮；把现有墙体按钮移入独立的 `plan-tools`，将原 `edit-tools` 明确为电路工具；在 `#canvas-container` 增加用于顶视编辑的 SVG 层。
- 修改 `css/style.css`：增加顶视图画布、网格、墙体、透明拾取线、悬停/选中状态、端点与交点控制柄、尺寸标签、无效预览及各工具光标样式；模式切换时正确显示 3D canvas 或 2D SVG。

### 2. 新增独立的 2D 户型编辑器

- 新建 `js/plan2d.js`，实现 `Plan2D` 类，集中管理：
  - SVG 世界坐标/屏幕坐标转换、缩放、平移和适应视图；
  - 墙体及控制点渲染、加宽拾取区域、画墙预览和尺寸提示；
  - 选择、正交画墙、任意画墙、墙身拖动、端点/交点拖动、吸附和取消操作；
  - 由现有 `walls` 派生的连接图（端点—端点、端点—墙内部），以及共点/T 型连接的联动更新；
  - 拖动前快照、全受影响墙校验、提交后 `onChange`，以及通过 `onSelect`、`onNotify`、`onDeleteWall` 与主程序协作。
- 复用 `model.js` 的 `createWall`、`wallLen`、`wallDir` 等函数，不引入依赖，不改变 JSON 版本或默认数据格式。

### 3. 主程序模式与旧功能迁移

- 修改 `js/main.js`：
  - 实例化并装配 `Plan2D`，扩展 `setMode` 以处理 `view / edit / plan` 三种模式、上下文工具栏、动态提示、3D 控制器禁用/恢复和 SVG 激活/关闭。
  - 删除 `addWallPending`、`wallP1`、3D 画墙点击逻辑及 `drawWallPreview` 等旧实现；保留的 3D 编辑只处理强电箱和电路实体。
  - 将删除墙、快捷键、导入后刷新和模式切换接到新编辑器；首堵墙创建后仍自动在墙中点建立强电箱。
  - 刷新时在户型模式下同步 2D，在返回 3D 时重建并正确 resize；墙面展开只允许查看/电路编辑模式。
- `scene3d.js` 保持 3D 渲染职责，不再承担画墙预览；必要时只调整模式可用性，不复制 2D 编辑逻辑。

### 4. 属性面板与文档

- 修改 `js/panel.js`：让 `update` 接收当前模式。户型模式选中墙时显示可编辑长度及只读高度/厚度，不显示“A/B 面”和“展开该面”等电路操作；长度编辑通过事件交回 `Plan2D` 执行联动。查看/电路模式保持原有墙面详情。
- 更新 `README.md`：记录三个模式、2D 顶视操作、吸附/联动规则及新增文件，移除“在 3D 中画墙”的旧说明。
- 同步调整相关代码注释，不新增与项目无关的测试或脚手架文件。

## 三、验证清单

项目无构建和既有测试套件，完成后用静态服务器和浏览器做端到端验证：

1. 默认户型正常加载；三个模式切换后工具栏、提示和画布正确，原 3D 查看、墙面展开、电路编辑、强电箱拖动不回归。
2. 在空白/默认户型分别添加水平、竖直和任意角度墙；验证网格/端点/墙面吸附、`Alt` 临时禁用、长度角度预览、`Esc` 取消和短墙拒绝。
3. 验证滚轮缩放、空白拖动平移和适应视图，编辑过程中坐标映射保持准确。
4. 用默认户型验证联动：拖动外角会同时修改相邻两墙；上下平移中间横墙 `w5` 时，竖墙 `w6` 的连接端随动；平移 `w6` 时其在上下横墙上的 T 型连接保持；拖动 T 型交点只能沿宿主墙滑动。
5. 拖端点和用右侧面板修改长度都能得到一致结果；相关墙上的设备、线路和强电箱仍正确定位，过长缩短会被拒绝且数据恢复原状。
6. 删除普通墙、尝试删除强电箱所在墙、导出再导入 JSON，确认引用清理和数据兼容性保持原行为。

## 四、电路编辑/预览中的逻辑墙段（派生拆分）

- 上文"不隐式拆墙"仅指**户型编辑层**：`plan2d` 始终操作原始整墙，不为移动交点而拆数据。
- 当一堵墙被 T 型/X 型交叉分到两个不同房间（含拖动后重新分房）时，**电路编辑与 3D 预览**把它视为多面独立的"逻辑墙段"：墙面展开按段进行（标题显示"段 N"）、查看模式按段判断是否有电路、hover 面框只高亮所在段。
- **纯派生、零数据转换**：`data.walls` 永远保存整墙；段由 `detectRooms` 顺带产出的每墙子段房间归属（`segRooms`）经 `buildWallSegments` 合并相邻同归属子段得到，随几何实时重算。删除隔断墙、拖走交叉墙后段自动合并，无需迁移任何持久化数据。
- **归一化坐标**：节点 `pos` 为沿原始墙的 0~1（schema version 1→2，旧文件导入时 `normalizeData` 自动除以墙长迁移；门保持绝对米数）。墙段内按半开区间 `[t0,t1)` 归属节点（末段闭区间，恰在切点上的节点归右侧段），立面对话框内部统一换算为"段内米制"显示与编辑。
- 跨段的已有电线在本段视图中画虚线到段边界；跨段连通经"穿墙连通"links 完成（段交界处的端点 3D 距离≈0，天然是连通候选）。
- 未拆分的墙恒为单段 `[0,1]`，行为与原先整墙一致。
