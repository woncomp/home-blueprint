# 家庭强电设计器

纯前端的家庭强电电路设计与预览工具，直接部署在 GitHub Pages 上即可运行，无需构建、无后端。

## 运行

任意静态服务器指向本目录即可，例如：

```bash
python -m http.server 8000
# 打开 http://localhost:8000
```

> 注意：Three.js 通过 CDN（jsdelivr）加载，首次打开需要联网。

## 部署到 GitHub Pages

把本目录内容推送到仓库，仓库 Settings → Pages → 选择分支根目录即可，无需任何构建配置。

## 使用说明

### 查看模式（默认）

- **摄像机**：WASD 在房屋内平移聚焦视点；左键拖动围绕聚焦视点旋转；滚轮拉远拉近。
- **选中**：点击电线 / 设备 / 端点 / 墙 / 强电箱，右侧信息栏显示详情。
- **强电箱**：右侧信息栏上半部分始终是强电箱 2D 布局，点击某个断路器可在 3D 中高亮其线路。
- **墙面展开**：双击某面墙，弹出该墙某一面的 2D 正视图，浏览该面电路。墙被隔断分到两个房间时按"逻辑墙段"分别展开（见下文）。

### 电路编辑

- **强电箱**：永远存在，不可删除；选中后按住即可沿墙水平拖动（不能调整高度）。
- **端点与设备**：双击墙面进入 2D 展开视图，使用工具条放置转弯端点、分线端点、插座、开关、灯具；选择工具下可拖动节点调整沿墙位置与离地高度。
- **三墙展开与横向滚动**：2D 展开视图除当前墙外，同时显示左右两面相邻墙的墙面（按面对墙体的视角排成左/当前/右三个独立槽位，三面墙共用同一比例、底边对齐）。每个槽位至少占可视编辑区宽度的 1/3，且只在本槽墙面较宽时扩展；左墙贴本槽右缘、右墙贴本槽左缘，当前墙保持居中，实际相邻墙面之间不额外加大间隔。最高墙恰好填满标题栏与底部刻度之间的可用高度，较矮墙按自身设置高度显示。总宽超出窗口时可横向滚动。普通重绘保留滚动位置，打开对话框、切换当前墙或窗口尺寸变化后自动把当前墙居中。
- **当前墙切换**：相邻墙面板标题右侧有"设为当前墙"按钮，点击后该墙（含其逻辑墙段）成为新的编辑中心，左右邻墙随之重新计算并居中；当前工具与模式保留，未完成连线、拖动与选择自动清理。左右邻墙取自同一房间（或外表面）有向边界环上的前驱/后继：与当前墙同属一个房间，宿主墙被 T 型接点拆段但房间不变时返回合并后的整面范围，从任一墙面沿同一方向连续切换会绕房间边界一圈回到起点。
- **相邻墙只读**：左右邻墙可查看、可选中、其节点可作为连线端点，但放置、删除、拖动与属性编辑仅限当前墙；要编辑邻墙请先"设为当前墙"。
- **删除**：电路编辑模式下（2D 与 3D 一致），删除节点、电线、穿墙连通统一从右侧信息面板发起——选中对象后点击"删除节点 / 删除电线"，穿墙连通在节点详情中逐条删除；顶部工具栏与 2D 工具条不提供删除入口。强电箱与端子不可删除，相邻墙（只读）节点不显示删除按钮。
- **连线**：2D 视图中"➰ 连线"，依次点击两个端点：支持当前墙内同面连线，也支持当前墙与左右相邻墙之间的**跨墙电线**（不受距离限制，写入 `wires`）；3D 中跨墙电线沿两面墙和公共拐角走线（起点→起点高度的公共角点→终点高度的公共角点→终点）。左右邻墙之间不能直接连线。
- **穿墙连通**："⇄ 穿墙连通"工具点击一个端点，选择候选（另一面对应点或转角相邻墙的端点）建立电线穿墙/转角连通。与跨墙电线的区别：`links` 是同一位置两面墙体的就近连通（0.4m 内），不画普通电线；跨墙电线用于沿墙走远线的真实连线。
- **断路器**：右侧强电箱面板"＋ 添加断路器"；每个断路器有左、右两个端子，可同时分别接线，2D 视图中点击任一端子与节点连线即归入该断路器（一个断路器的所有下游电路视为同一条线路，同色同统计）。
- **颜色规则**：线路（电线、转弯/分线端点）按断路器分配颜色；**插座颜色始终跟随所属线路颜色**（3D 视图与 2D 墙面展开一致），未接线路时回退默认类型色；开关、灯具保持各自类型色不变。
- **说明文字**：设备 / 电线 / 断路器均可在属性面板中填写标注。
- **逻辑墙段**：新建或拖动墙体使一面墙被分到两个不同房间（T 型 / X 型交叉）时，电路编辑与 3D 预览把它视为多面独立的墙段，各自展开；墙上的电气对象按归一化位置自动落入所属墙段。删除隔断墙后段自动合并。查看模式下墙体的可拾取资格按原始整墙判断（墙任意一段有电路或墙上有强电箱即可拾取整墙），展开与高亮仍按段。户型编辑层始终操作原始整墙，持久化数据不变。

### 户型编辑

切换到独立的 2D 顶视图（X 向右、Z 向下）编辑户型，墙体围出封闭空间即形成房间，房间可在 3D 中点击后命名。

- **视图导航**：滚轮以鼠标为中心缩放；空白处按住左键拖动平移；"⛶ 适应视图"把全部墙体缩放到画布中央（进入本模式和导入数据时自动适应一次）。
- **画墙**："📐 正交画墙"自动锁定水平/竖直，"✏ 任意画墙"允许任意角度；单击起点再单击终点，过程中实时显示长度和角度。成功创建一堵墙后自动回到"选择"工具，再次添加需重新点击画墙工具；墙太短未创建时保持当前工具，重新点击起点即可；`Esc` 取消当前预览或退回"选择"。默认吸附 0.1m 网格、已有墙端点和墙面投影（便于建立转角/T 型连接），按住 `Alt` 临时关闭吸附；短于 0.2m 的墙不创建。首堵墙创建后自动在墙中点放置强电箱。
- **操作提示**：顶部工具栏不显示操作说明；未选中对象时，右侧"信息"面板显示当前工具的提示（选择工具显示默认操作说明，画墙工具在点击起点后切换为第二端点阶段提示）。
- **选择**：单击墙、门或控制点选中，单击空白清除；`Delete` 删除选中的墙或门，选中墙/门后也可在右侧信息面板点击"删除墙"/"删除门"（强电箱所在墙不可删除）。
- **门**："🚪 添加门"点击墙身在点击位置开门（0.1m 吸附，Alt 关闭），成功后自动回到"选择"工具并选中新门，`Esc` 退出；选择工具下拖动门沿墙移动，靠近其他墙时自动换墙；选中后门宽可精确编辑、可翻面开门方向；3D 中墙体真实开洞并带门框与半开门扇。
- **强电箱**：顶视图中可见（方块标记），选择工具下可直接沿墙拖动，端子与 3D 自动同步。
- **拖动墙身**：沿墙法线前后平移，不改变墙长和角度，实时显示位移量。
- **拖动端点/交点**：自由拖动独立端点改变长度和方向；重合的墙端只显示一个控制点，拖动时所有共用墙端一起移动；墙端落在另一墙内部的 T 型交点只能沿宿主墙滑动。
- **联动与校验**：平移墙时共端点相邻墙端随动，其上的 T 型相连墙端按相同沿墙位置随动；所有受影响墙统一检查最小长度和墙面元素边界。节点/设备/强电箱使用沿墙 0~1 归一化坐标，墙长变化时按相同比例随动、不会落出墙外；门仍是绝对米数，若修改会使门洞落在墙外或断开 T 型连接，本次修改无效并还原。
- **精确长度**：选中墙后右侧信息栏可编辑长度，保持方向和起点不变，仅移动终点，联动与校验与拖动一致。
- 拖动过程中只重绘 2D，松开鼠标且修改有效后统一刷新 3D、房间与线路；`Esc` 取消拖动并恢复拖动前快照。

### 数据保存

- 打开时自动加载 `data/default.json` 作为默认户型。
- 工具栏"查看 JSON"打开接近全屏的弹窗，以缩进格式展示当前布局 JSON，可直接编辑：
  - **应用**：先解析、迁移并校验文本，全部通过后才整体替换当前布局并刷新 3D / 2D / 面板；失败时只在弹窗标题栏显示错误原因，实际布局不变，文本也保留。
  - **保存文件**：把文本框当前内容下载为 `electrical-design.json`，不校验也不影响当前布局（未编辑时等同导出当前数据）。用下载文件替换源码中的 `data/default.json` 即可更新默认布局。
  - **关闭**：点击关闭按钮、遮罩或按 `Esc` 只关闭弹窗，不自动应用未应用的编辑。

## 数据格式

见 `data/default.json`。核心结构：

- `version`：数据版本，当前为 3。版本 1 的节点 `pos` 为沿墙米数，加载/应用 JSON 时先迁移为 0~1 归一化坐标；版本 1/2 的断路器单一 `terminal` 端子自动升级为左右双端子（见 `breakerBox`），原端子 ID 与电线引用全部保留。
- `walls`：线段墙（起点/终点/高度/厚度），围出封闭环即房间；持久化层始终保存原始整墙，不因房间归属而拆分。
- `nodes`：墙面上的点，`type` 为 `turn`（转弯）/ `split`（分线）/ `device`（设备）/ `terminal`（强电箱端子），含 `wall`、`face`（0=A 面，1=B 面）、`pos`（**沿原始墙的 0~1 归一化坐标**，0=起点端、1=终点端）、`height`（离地高度，米）。
- `wires`：连接两个节点的电线；可以是当前墙同面两点，也可以是相邻两面墙上的点（跨墙电线，3D 沿公共拐角走线）。
- `links`：节点间就近连通（穿墙两面、转角相邻墙，0.4m 内的端点对），电线经此跨墙延续；与跨墙 `wires` 互补，不画普通电线。
- `doors`：墙上的门，`wall`（所在墙）、`pos`（门中心沿墙距离）、`width`（门洞宽，默认 0.9）、`face`（开门方向 0/1）、`height`（门高，默认 2.0）；3D 中墙体在门洞处真实开洞。旧版数据没有该字段，导入时自动补空数组。
- `breakerBox`：强电箱位置与断路器列表。每个断路器拥有左、右两个可同时接线的端子（`terminals.left / terminals.right`，各为 `nodes` 中一个 `terminal` 节点，横向固定在箱体左右边缘内缩 1cm 处、同一行高）；从任一端子接出的下游电线都归入同一条线路，运行时按断路器分配颜色。端子不可单独删除或拖动，随强电箱同步位置。

## 文件结构

```
index.html          入口页面
css/style.css       样式
js/main.js          启动与各模块装配、三模式切换
js/model.js         数据模型、房间环检测、线路计算
js/json-dialog.js   “查看 JSON”弹窗（编辑 / 应用 / 保存文件）
js/scene3d.js       3D 场景渲染与拾取
js/plan2d.js        户型编辑 2D 顶视图（画墙、拖动、吸附与连接联动）
js/controls.js      聚焦视点摄像机
js/wallface.js      墙面 2D 展开对话框
js/panel.js         右侧信息栏
js/persistence.js   JSON 解析、校验与下载
data/default.json   默认户型数据
```
