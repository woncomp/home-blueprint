# 家庭强电设计器

纯前端的家庭强电电路设计与预览工具，直接部署在 GitHub Pages 上即可运行，无需构建、无后端。

## 运行

任意静态服务器指向本目录即可，例如：

```bash
python -m http.server 8000
# 打开 http://localhost:8000
```

> 注意：Three.js 通过 CDN（jsdelivr）加载，首次打开需要联网。

## 部署到 GitHub Pages

把本目录内容推送到仓库，仓库 Settings → Pages → 选择分支根目录即可，无需任何构建配置。

## 使用说明

### 查看模式（默认）

- **摄像机**：WASD 在房屋内平移聚焦视点；左键拖动围绕聚焦视点旋转；滚轮拉远拉近。
- **选中**：点击电线 / 设备 / 端点 / 墙 / 强电箱，右侧信息栏显示详情。
- **强电箱**：右侧信息栏上半部分始终是强电箱 2D 布局，点击某个断路器可在 3D 中高亮其线路。
- **墙面展开**：双击某面墙，弹出该墙某一面的 2D 正视图，浏览该面电路。

### 电路编辑

- **强电箱**：永远存在，不可删除；选中后按住即可沿墙水平拖动（不能调整高度）。
- **端点与设备**：双击墙面进入 2D 展开视图，使用工具条放置转弯端点、分线端点、插座、开关、灯具；选择工具下可拖动节点调整沿墙位置与离地高度。
- **连线**：2D 视图中"➰ 连线"，依次点击同面两个端点。
- **穿墙连通**："⇄ 穿墙连通"工具点击一个端点，选择候选（另一面对应点或转角相邻墙的端点）建立电线穿墙/转角连通。
- **断路器**：右侧强电箱面板"＋ 添加断路器"；在 2D 视图中把强电箱端子与节点连线即归入该断路器（一个断路器的所有下游电路视为同一条线路）。
- **说明文字**：设备 / 电线 / 断路器均可在属性面板中填写标注。

### 户型编辑

切换到独立的 2D 顶视图（X 向右、Z 向下）编辑户型，墙体围出封闭空间即形成房间，房间可在 3D 中点击后命名。

- **视图导航**：滚轮以鼠标为中心缩放；空白处按住左键拖动平移；"⛶ 适应视图"把全部墙体缩放到画布中央（进入本模式和导入数据时自动适应一次）。
- **画墙**："📐 正交画墙"自动锁定水平/竖直，"✏ 任意画墙"允许任意角度；单击起点再单击终点，过程中实时显示长度和角度。完成一堵后工具保持激活，`Esc` 取消当前预览或退回"选择"。默认吸附 0.1m 网格、已有墙端点和墙面投影（便于建立转角/T 型连接），按住 `Alt` 临时关闭吸附；短于 0.2m 的墙不创建。首堵墙创建后自动在墙中点放置强电箱。
- **选择**：单击墙或控制点选中，单击空白清除；`Delete` 删除选中的墙（强电箱所在墙不可删除），也可用"✕ 删除墙"工具点击删除。
- **拖动墙身**：沿墙法线前后平移，不改变墙长和角度，实时显示位移量。
- **拖动端点/交点**：自由拖动独立端点改变长度和方向；重合的墙端只显示一个控制点，拖动时所有共用墙端一起移动；墙端落在另一墙内部的 T 型交点只能沿宿主墙滑动。
- **联动与校验**：平移墙时共端点相邻墙端随动，其上的 T 型相连墙端按相同沿墙位置随动；所有受影响墙统一检查最小长度和墙面元素边界，若修改会使节点/设备/强电箱落在墙外或断开 T 型连接，本次修改无效并还原。
- **精确长度**：选中墙后右侧信息栏可编辑长度，保持方向和起点不变，仅移动终点，联动与校验与拖动一致。
- 拖动过程中只重绘 2D，松开鼠标且修改有效后统一刷新 3D、房间与线路；`Esc` 取消拖动并恢复拖动前快照。

### 数据保存

- 打开时自动加载 `data/default.json` 作为默认户型。
- "导出 JSON"下载当前数据；用导出文件替换源码中的 `data/default.json` 即可更新默认布局。
- "导入 JSON"从本地文件加载数据。

## 数据格式

见 `data/default.json`。核心结构：

- `walls`：线段墙（起点/终点/高度/厚度），围出封闭环即房间。
- `nodes`：墙面上的点，`type` 为 `turn`（转弯）/ `split`（分线）/ `device`（设备）/ `terminal`（强电箱端子），含 `wall`、`face`（0=A 面，1=B 面）、`pos`（沿墙距离）、`height`（离地高度）。
- `wires`：连接同面两个节点的电线。
- `links`：节点间连通（穿墙两面、转角相邻墙），电线经此跨墙延续。
- `breakerBox`：强电箱位置与断路器列表；线路由断路器端子沿 wires+links 连通计算得出，运行时按断路器分配颜色。

## 文件结构

```
index.html          入口页面
css/style.css       样式
js/main.js          启动与各模块装配、三模式切换
js/model.js         数据模型、房间环检测、线路计算
js/scene3d.js       3D 场景渲染与拾取
js/plan2d.js        户型编辑 2D 顶视图（画墙、拖动、吸附与连接联动）
js/controls.js      聚焦视点摄像机
js/wallface.js      墙面 2D 展开对话框
js/panel.js         右侧信息栏
js/persistence.js   JSON 导入导出
data/default.json   默认户型数据
```
